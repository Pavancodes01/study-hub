Idea to code in four questions

When you have the idea but can't write it, answer these in order. Each answer is one or two lines of code.

  1. Where do pointers start?Gives your first line: int left = 0, right = n - 1;
  2. When should I stop?Gives the loop: while (left < right)
  3. In each case, which pointer moves?Gives the if / else with left++ or right--. Every branch must move something.
  4. What do I return?A pair, a count, a length, true / false, or the modified array.

Opposite ends

One pointer at the start, one at the end. They walk toward each other and stop when they meet. Works because the array is sorted (or because you compare mirror positions).

int left = 0, right = arr.length - 1;
Use it when
Sorted array + pair sum, reverse, palindrome, container with most water.
Loop
while (left < right) because you need two different items.
How to move
  • Sum too small: left++ (bigger values are on the right)
  • Sum too big: right-- (smaller values are on the left)
  • Match or swap done: left++; right--;
  • Container problems: move the side with the smaller height
Cost
O(n) time, O(1) space.
Practice: 167 Two Sum II, 125 Valid Palindrome, 344 Reverse String, 11 Container With Most Water, 680 Valid Palindrome II
int[] twoSum(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left < right) {
        int sum = arr[left] + arr[right];
        if (sum == target) {
            return new int[]{left, right};
        } else if (sum < target) {
            left++;          // need a bigger sum
        } else {
            right--;         // need a smaller sum
        }
    }
    return new int[]{-1, -1};   // not found
}
boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        char a = s.charAt(left);
        char b = s.charAt(right);
        if (!Character.isLetterOrDigit(a)) { left++;  continue; }
        if (!Character.isLetterOrDigit(b)) { right--; continue; }
        if (Character.toLowerCase(a) != Character.toLowerCase(b)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

continue jumps back to the while check after moving just one pointer.

void reverse(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char temp = s[left];     // swap in 3 lines
        s[left] = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}
int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int best = 0;
    while (left < right) {
        int h = Math.min(height[left], height[right]);
        int width = right - left;
        best = Math.max(best, h * width);
        if (height[left] < height[right]) left++;   // move the shorter wall
        else right--;
    }
    return best;
}

Read and write (same direction)

Both pointers go left to right. read looks at every item. write marks where the next item you keep should go. Everything before write is the answer.

int write = 0; for (int read = 0; read < n; read++)
Use it when
"In place", "O(1) extra space", "return the new length", move zeroes, remove duplicates.
Loop
A normal for loop on read. It moves every time by itself.
How to move
  • read: every step (the for loop does it)
  • write: only when you keep an item: nums[write] = nums[read]; write++;
Return
write is the new length.
Practice: 26 Remove Duplicates, 27 Remove Element, 283 Move Zeroes, 80 Remove Duplicates II
int removeElement(int[] nums, int val) {
    int write = 0;
    for (int read = 0; read < nums.length; read++) {
        if (nums[read] != val) {      // keep it
            nums[write] = nums[read];
            write++;
        }
    }
    return write;                      // new length
}
int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int write = 1;                     // nums[0] is always kept
    for (int read = 1; read < nums.length; read++) {
        if (nums[read] != nums[write - 1]) {   // new value
            nums[write] = nums[read];
            write++;
        }
    }
    return write;
}
void moveZeroes(int[] nums) {
    int write = 0;
    for (int read = 0; read < nums.length; read++) {
        if (nums[read] != 0) {
            int temp = nums[write];    // swap keeps the zeros behind
            nums[write] = nums[read];
            nums[read] = temp;
            write++;
        }
    }
}

Fast and slow (linked lists)

Both start at the head. slow moves one node, fast moves two. If there is a loop, fast catches slow. When fast reaches the end, slow is in the middle.

ListNode slow = head, fast = head;
Use it when
Cycle detection, middle of list, nth node from end, palindrome linked list, happy number.
Loop
while (fast != null && fast.next != null). Fast jumps two, so both must exist. Check fast first.
How to move
  • slow = slow.next;
  • fast = fast.next.next;
  • Nth from end: move fast ahead n steps first, then move both by one
Compare nodes
Use slow == fast (same node object), not the values.
Practice: 141 Linked List Cycle, 876 Middle of the Linked List, 19 Remove Nth Node From End, 142 Linked List Cycle II, 234 Palindrome Linked List
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;           // 1 step
        fast = fast.next.next;      // 2 steps
        if (slow == fast) return true;
    }
    return false;                   // fast fell off the end
}
ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;     // for even length, this is the 2nd middle
}
ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);   // handles removing head
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) {            // make a gap of n + 1
        fast = fast.next;
    }
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;                // skip the target
    return dummy.next;
}

Two sequences

One pointer per array or string. Compare the two current items, then move the pointer whose item you just used.

int i = 0, j = 0;
a
b
Use it when
Merge two sorted lists, is-subsequence, intersection of sorted arrays, compare version strings.
Loop
while (i < a.length && j < b.length). Stops when either runs out.
How to move
  • Took from a: i++. Took from b: j++.
  • Equal and you need both: i++; j++;
  • After the loop, copy leftovers with two small while loops
Shortcut
res[k++] = a[i++]; means: use the current index, then add 1 to it.
Practice: 392 Is Subsequence, 21 Merge Two Sorted Lists, 349 / 350 Intersection of Arrays, 844 Backspace String Compare
int[] merge(int[] a, int[] b) {
    int[] res = new int[a.length + b.length];
    int i = 0, j = 0, k = 0;
    while (i < a.length && j < b.length) {
        if (a[i] <= b[j]) res[k++] = a[i++];
        else              res[k++] = b[j++];
    }
    while (i < a.length) res[k++] = a[i++];   // leftovers of a
    while (j < b.length) res[k++] = b[j++];   // leftovers of b
    return res;
}
boolean isSubsequence(String s, String t) {
    int i = 0, j = 0;
    while (i < s.length() && j < t.length()) {
        if (s.charAt(i) == t.charAt(j)) {
            i++;            // matched, move to next char of s
        }
        j++;                // t always moves
    }
    return i == s.length();  // matched every char of s?
}

Fix one, then pair

Sort first. A for loop fixes one number, then run opposite ends on the rest to find the other two. This turns 3Sum from O(n³) into O(n²).

Arrays.sort(nums); left = i + 1, right = n - 1
Use it when
3Sum, 3Sum closest, 4Sum, count triplets with a condition.
Loop
Outer for (int i = 0; i < n - 2; i++), inner while (left < right).
Skip duplicates
  • For i: if (i > 0 && nums[i] == nums[i - 1]) continue;
  • After a match, skip equal neighbours of left and right, and keep left < right inside those loops
4Sum
Two outer loops, then the same pair search. Use long for the sum.
Practice: 15 3Sum, 16 3Sum Closest, 18 4Sum, 259 3Sum Smaller
List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                                   // must sort
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // skip same i
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
int threeSumClosest(int[] nums, int target) {
    Arrays.sort(nums);
    int best = nums[0] + nums[1] + nums[2];
    for (int i = 0; i < nums.length - 2; i++) {
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (Math.abs(sum - target) < Math.abs(best - target)) {
                best = sum;
            }
            if (sum < target) left++;
            else if (sum > target) right--;
            else return sum;          // exact match
        }
    }
    return best;
}

Three-way split (Dutch flag)

Three pointers make three zones: 0s before low, 1s between low and mid, 2s after high. mid scans the unknown middle part.

int low = 0, mid = 0, high = nums.length - 1;
Use it when
Sort colors (0, 1, 2), partition around a pivot, put negatives / zeros / positives into groups.
Loop
while (mid <= high). Uses <= because the item at high is not checked yet.
How to move
  • Got 0: swap(low, mid), low++, mid++
  • Got 1: mid++
  • Got 2: swap(mid, high), high-- only. Don't move mid: the value swapped in is still unchecked.
Practice: 75 Sort Colors, 905 Sort Array By Parity, 2161 Partition Array by Pivot
void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums, low, mid);
            low++;
            mid++;
        } else if (nums[mid] == 1) {
            mid++;
        } else {                    // nums[mid] == 2
            swap(nums, mid, high);
            high--;                 // mid stays: recheck new value
        }
    }
}

void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}

Fill from the back

When the biggest answer is easiest to find, write the result from the last index backwards. Nothing gets overwritten before it's read.

int i = m - 1, j = n - 1, k = m + n - 1;
nums1
nums2
Use it when
Merge into an array with free space at the end, squares of a sorted array (with negatives), add strings / binary numbers.
Loop
Counting down: while (j >= 0) or for (int k = n - 1; k >= 0; k--).
How to move
  • Put the bigger item at k, then move that pointer and k down
  • nums1[k--] = nums1[i--]; writes, then moves both left
Practice: 88 Merge Sorted Array, 977 Squares of a Sorted Array, 415 Add Strings, 67 Add Binary
void merge(int[] nums1, int m, int[] nums2, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    while (j >= 0) {                 // done when nums2 is used up
        if (i >= 0 && nums1[i] > nums2[j]) {
            nums1[k--] = nums1[i--];
        } else {
            nums1[k--] = nums2[j--];
        }
    }
}
int[] sortedSquares(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    int left = 0, right = n - 1;
    for (int k = n - 1; k >= 0; k--) {     // biggest square first
        if (Math.abs(nums[left]) > Math.abs(nums[right])) {
            res[k] = nums[left] * nums[left];
            left++;
        } else {
            res[k] = nums[right] * nums[right];
            right--;
        }
    }
    return res;
}

Loop conditions

The loop condition is where most off-by-one bugs live. Pick it by asking: "Do the pointers need two different items, or can they look at the same one?"

Pointer moves

Every branch of your if / else must move at least one pointer. If a branch moves nothing, the loop runs forever.

CodeWhat it doesWhen
left++;Move left pointer one step rightNeed a bigger value, or skip a bad char
right--;Move right pointer one step leftNeed a smaller value
left++; right--;Both move inwardAfter a match or a swap
res[k++] = a[i++];Use current k and i, then add 1 to bothMerging
nums1[k--] = nums2[j--];Use current indices, then subtract 1Filling from the back
slow = slow.next;

i++ and ++i do the same thing on their own line. They only differ inside an expression: a[i++] uses the old i, a[++i] uses the new one.

Common bugs

Check these before you hit Submit.

Infinite loop

One branch of the if / else doesn't move any pointer.

Fix: every branch ends with left++, right--, or both.

Forgot to sort

Opposite ends for pair sums only works on a sorted array.

Fix: Arrays.sort(nums). If you must return original indices, use a HashMap instead.

Index out of bounds while skipping

nums[left + 1] crashes at the end of the array.

Fix: always keep left < right && first in the skip loop.

NullPointerException in lists

fast.next.next when fast.next is null.

Fix: fast != null && fast.next != null, in that order.

Integer overflow

Adding 3 or 4 big ints goes past about 2.1 billion.

Fix: long sum = (long) a + b + c + d;

length vs length() vs size()

Arrays use .length, Strings use .length(), Lists use .size().

Wrong loop condition

Using < where the middle item needs checking (Dutch flag), or <= where you need two different items (pair sum).

Moving mid after swapping with high

The value that came from high hasn't been checked.

Fix: only high-- in that branch.
