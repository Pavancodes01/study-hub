How to study one pattern

About one to three days per pattern. The goal is not to remember solutions, it is to make the template automatic so your brain is free for the problem.

  1. Watch the demoStep through the animation at the top. Say out loud why each pointer or value moves.
  2. Read the templateFor each version, read the rules, then the code. Find where each rule shows up in the code.
  3. Fill the blanksDo the fill-in drills until they pass without hints. Then type the whole template once from memory.
  4. Idea to codeOrder the lines from the plain-English idea. This is the skill you said is missing: turning steps into Java.
  5. Solve, then re-solveDo the "Start here" problems. Solve each again the next day without looking. Tick it only then.

Idea to code, for any pattern

When you know the approach but freeze at the keyboard, write these four things as comments first, then turn each comment into one or two lines of Java.

  1. StateWhat variables describe "where I am"? Pointers, a window, a map, a stack, a dp array. Declare them.
  2. LoopWhat do I walk over, and when do I stop? This is your for / while line.
  3. StepFor each case, how does the state change? Every branch must make progress.
  4. AnswerWhere is the answer when the loop ends? What do I return for empty or "not found"?
